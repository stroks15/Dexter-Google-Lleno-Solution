Aviso de privacidad

Última actualización: 1 de noviembre de 2026

Este aviso explica cómo Dexter Google Lleno Solution (“Dexter”, “la aplicación”) trata la información cuando utilizas el sitio web y sus funciones de asistencia para Google Drive y Google Fotos. El correo de contacto para privacidad y soporte es dexterh4ck@gmail.com.

Enfoque de privacidad: Dexter guía al usuario para configurar funciones oficiales de Google, incluido Compartir con colaborador de Google Fotos. No realiza una copia binaria automática de fotos o videos ni elimina contenido de tus cuentas.

1. Información que podemos tratar

  • Datos de cuenta: identificador de usuario, dirección de correo y datos básicos de perfil proporcionados por el proveedor de inicio de sesión.
  • Datos de conexión de Google: cuando autorizas una función, la aplicación puede recibir tokens OAuth y datos de cuenta necesarios para ejecutar esa función. Los tokens se manejan en el servidor y se protegen mediante cifrado configurado por el servicio.
  • Datos operativos: estado del asistente, preferencias, registros técnicos y metadatos limitados necesarios para mostrar el progreso.
  • Datos de facturación: identificadores de órdenes, plan contratado, estado de pago y datos de cupón. Los pagos se procesan mediante Mercado Pago; Dexter no necesita almacenar los datos completos de tu tarjeta.

2. Cómo utilizamos la información

Utilizamos los datos para autenticarte, mantener tu sesión, conectar las cuentas que tú autorizas, mostrar el estado de la guía, administrar planes y suscripciones, prevenir fraude y dar soporte. Solo solicitamos permisos de Google que sean necesarios para las funciones que habilites.

3. Google Drive y Google Fotos

El acceso a Google se realiza mediante OAuth y requiere tu consentimiento. Puedes conectar cuentas distintas como origen y destino cuando la función lo permita. La aplicación puede trabajar con metadatos autorizados, pero la configuración de Compartir con colaborador, la aceptación de invitaciones y la acción de guardar elementos se realizan en los servicios oficiales de Google por decisión del usuario.

Dexter no afirma que una biblioteca se haya copiado íntegramente ni ofrece una verificación binaria completa de todos los archivos. No borra automáticamente fotos, videos ni archivos de Drive. El usuario conserva el control de sus cuentas y debe revisar el contenido directamente en Google.

4. Compartición con terceros

Podemos utilizar proveedores necesarios para operar el servicio, como Google para autenticación y funciones autorizadas, Supabase para autenticación y almacenamiento de datos de aplicación, Vercel para alojamiento, Upstash para caché y Mercado Pago para pagos. Estos proveedores procesan información conforme a sus propias condiciones y políticas. No vendemos datos personales.

5. Conservación y seguridad

Conservamos la información mientras sea necesaria para prestar el servicio, mantener registros de facturación, atender solicitudes o cumplir obligaciones aplicables. Aplicamos controles técnicos y de acceso razonables; ningún sistema puede garantizar seguridad absoluta. Los tokens y secretos no deben exponerse públicamente.

6. Tus opciones y eliminación

Puedes dejar de utilizar la aplicación, revocar los permisos de Google desde la configuración de seguridad de tu cuenta de Google y solicitar acceso, corrección o eliminación de datos de la aplicación escribiendo a dexterh4ck@gmail.com. Para procesar una solicitud podremos pedir información razonable para verificar que eres titular de la cuenta. Revocar permisos no elimina por sí mismo datos que ya estén almacenados por proveedores o que deban conservarse por obligaciones legales.

7. Menores de edad

El servicio no está dirigido a menores de 13 años. Si consideras que un menor nos proporcionó datos personales, contacta al correo indicado para revisar la solicitud.

8. Cambios a este aviso

Podemos actualizar este aviso cuando cambien las funciones o requisitos legales. Publicaremos la versión vigente en esta página e indicaremos la fecha de actualización.
